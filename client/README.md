# ChatGPT Clone - Client Frontend

React + Vite frontend for the ChatGPT Clone real-time conversational AI application.

## Tech Stack
- React 19
- Vite 8
- Tailwind CSS v4
- React Router DOM v7

## Scripts
- `npm run dev`: Start Vite development server
- `npm run build`: Build production assets
- `npm run preview`: Preview production build
